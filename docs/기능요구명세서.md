# ChartMate 기능요구명세서

- **프로젝트명**: ChartMate
- **목적**: 투자 초보가 겪는 ① 차트 해석의 어려움, ② 종목별 지표 조회의 번거로움을 대화형으로 해소
- **대상 사용자**: 개인 투자자, 특히 투자 초보
- **작성일**: 2026-11-03

---

## 1. 기능 요구사항 (FR)

| ID | 기능명 | 설명 | 우선순위 |
|----|--------|------|----------|
| FR-01 | 대화형 질의응답 | 사용자가 종목·투자 관련 질문을 입력하면 AI 비서가 자연어로 응답 | Must |
| FR-02 | 실시간 시세·지표 조회 (Agent) | 질문 의도를 파악해 `get_price`·`get_indicators` 툴을 호출, 현재가·등락률·이동평균·모멘텀·ATR을 조회해 해석과 함께 전달 | Must |
| FR-03 | 차트 이미지 해석 (멀티모달) | 사용자가 올린 차트 이미지를 Gemini 비전으로 읽어 추세·주요 구간을 자연어로 설명 | Must |
| FR-04 | 대화기록 저장·맥락 유지 (LTM) | 사용자별 대화 기록을 저장, 다음 대화에서 이전 맥락을 자동 로드 | Must |
| FR-05 | 관심종목 관리 | 사용자가 관심종목을 등록·조회·삭제, 이후 질의 시 맥락으로 활용 | Should |
| FR-06 | AI 고지·투자 유의 표시 | "AI 생성 콘텐츠 / 투자 참고용, 투자자문 아님"을 UI에 상시 표시 | Must |
| FR-07 | 개인정보 수집 동의 | 데이터 수집 전 동의 절차 제공 | Must |
| FR-08 | 사용자 피드백 수집 | 서비스 내 또는 외부 폼으로 피드백 수집 | Could |

## 2. 비기능 요구사항 (NFR)

| ID | 항목 | 요구사항 |
|----|------|----------|
| NFR-01 | 응답 속도 | 일반 질의 응답 5초 이내 (시세 조회·이미지 해석 포함 질의는 별도 안내) |
| NFR-02 | 가용성 | 외부 접근 가능한 상태로 상시 배포 (Render · Vercel) |
| NFR-03 | 개인정보 | 동의 후 수집, Firestore에 저장, 민감정보 미수집 |
| NFR-04 | 오류 처리 | 시세 미수신·이미지 판독 실패 시 사용자에게 명확히 안내하고 재시도 유도 (무응답·크래시 금지) |

## 3. AI 활용 명세

| 기능 | AI 활용 방식 | 상세 |
|------|-------------|------|
| 대화 응답 | LLM (OpenAI) | 시스템 프롬프트에 관심종목·대화요약 주입, '현황 설명·지표 해석'에 한정 |
| 시세·지표 조회 | AI Agent (function calling) | 사용자 의도 → 툴 선택·호출 → 결과를 해석해 응답 |
| 차트 해석 | 멀티모달 (Gemini 비전, `gemini-3.5-flash`) | 차트 이미지 입력 → 추세·지지/저항 '관찰' 서술 (예측 아님) |
| 맥락 유지 | Long-term Memory (Firestore) | 사용자별 기록 저장·로드 |

## 4. 시스템 아키텍처

```
사용자(브라우저)
  → Vercel 프론트 (채팅 UI + 차트 이미지 업로드 + 고지 배너)
  → FastAPI (Render)
       ├─ OpenAI API       : 대화 응답 (AI 비서 본체)
       ├─ Gemini 비전        : 차트 이미지 해석 (멀티모달)
       ├─ 시세/지표 조회 툴   : yfinance (Agent function calling)
       └─ Firestore         : 관심종목·대화기록 (Long-term Memory)
```

(발표·제출용 다이어그램 이미지는 `/docs/images/architecture.png`에 첨부)

## 5. 데이터 모델 (Firestore, 개요)

- `users/{uid}`
  - `watchlist`: 관심종목 티커 배열
  - `created_at`, `consent`: 가입 시각, 개인정보 동의 여부
- `users/{uid}/messages/{msgId}`
  - `role`(user/assistant), `content`, `created_at`

(구조는 선행 '데이터 AI 비서' 프로젝트의 Firestore 설계를 재사용·확장)

## 6. 예외 흐름 (FR-02/FR-03 상세)

- **티커 오류·시세 API 실패** → "해당 종목 정보를 가져오지 못했습니다. 티커를 확인해 주세요." + 재시도.
- **차트가 아니거나 판독 불가 이미지** → "차트로 인식하지 못했습니다. 캔들/라인 차트 이미지를 올려 주세요."
- **LLM 응답 지연·실패** → 로딩 표시 후 실패 시 재시도 안내.
